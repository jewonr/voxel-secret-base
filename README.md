# 시크릿 베이스: 백신 구출작전

**만든이: 도윤**

가운데 **비밀기지 코어**를 좀비로부터 지키면서 기지를 100% 완공하는 3D 복셀 디펜스 게임입니다. 코인을 모아 **백신 총**을 사면, 좀비를 쏴서 우리 편 시민으로 되돌릴 수 있습니다.

▶ **플레이:** https://jewonr.github.io/voxel-secret-base/

## 조작법

| 키 | 동작 |
| --- | --- |
| **WASD** | 이동 |
| **Q / E** | 회전 |
| **SPACE** | 사격 (자동 조준) |
| **1 / 2** | 무기 바꾸기 |
| **R** | 대시 충격파 |
| **B** | 기지 건설 창 |
| **T** | 백신 연구소 상점 |

모바일에서는 화면의 가상 조이스틱과 버튼으로 조작합니다.

## 규칙

- 전투 중에 떨어지는 아이템을 주우면 **코인(🪙)**, **자원(🧱)**, 실드 회복을 얻음
- 자원으로 **방벽 · 레이저 터렛 · 힐링 비콘**을 지으면 기지 완공률이 올라감
- 코인으로 **백신 총**, 코어 수리, 시민 강화 혈청을 살 수 있음
- 백신 총에 맞은 좀비는 시민 아군이 됨 — 단, 시민이 좀비에게 물리면 다시 감염됨!
- 기지를 100% 완공하면 승리, 코어가 파괴되면 실패
- 시작 화면에서 히든 코드(`#비밀기지`, `7777`, `9999`)를 입력할 수 있음

## 파일

`index.html` 하나에 모든 코드(HTML · CSS · JavaScript)가 들어 있습니다. 3D 그래픽은 three.js, 효과음은 Web Audio API로 코드에서 직접 만들어 냅니다.
